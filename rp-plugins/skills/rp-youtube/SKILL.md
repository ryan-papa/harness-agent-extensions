# rp-youtube — 유튜브 영상 분석

영상은 37분을 봐야 알 수 있고, 다시 찾기도 어렵다. 자막을 받아 타임스탬프가 붙은 전사본으로 만들고, 무슨 주장을 어떤 근거로 했는지 구조화해 3분 만에 파악하게 한다.

## 레퍼런스

| 파일 | 역할 |
|------|------|
| [`scripts/fetch_transcript.py`](scripts/fetch_transcript.py) | 메타데이터 + 자막 → 타임스탬프 전사본. yt-dlp 자동 설치, 클라이언트 폴백, 접근 게이트 판정 (stdlib only) |

## 입력

| 인자 | 동작 |
|------|------|
| 유튜브 URL (`watch?v=` · `youtu.be/` · `shorts/` · `live/`) | 그 영상을 분석 |
| 없음 | **링크를 한 번 물어본다.** ⛔ 이전 대화·클립보드·추측으로 대상을 정하지 않는다 |
| URL + 요청 (`~관점으로 정리해줘`) | 분석 초점을 그 요청에 맞춘다 |

`&t=547s` 같은 파라미터가 붙어 있어도 그대로 넘긴다(스크립트가 영상 ID만 뽑는다).

## 워크플로우

1. **전사본 확보** — 작업 디렉터리를 정하고 스크립트를 돌린다.

   ```
   python3 <스킬경로>/scripts/fetch_transcript.py <URL> --out <작업디렉터리> --json
   ```

   - **작업 디렉터리**: 스크래치패드가 있으면 그 아래 `yt/`, 없으면 `~/.rp-youtube/work/`. ⛔ 사용자 레포 안에 전사본·메타 파일을 만들지 않는다.
   - `--langs ko,en`으로 선호 언어를 줄 수 있다. 기본은 **영상 원어 → 한국어 → 영어** 순.
   - yt-dlp가 없으면 `~/.rp-youtube/venv`에 자동 설치한다(최초 1회 약 30초).
   - **종료 코드로 분기한다**: `0` 성공 / `2` 자막 없음 / `3` 접근 불가 / `4` 설치 실패. (§접근 불가·자막 없음)
2. **전사본·메타 읽기** — `<id>.transcript.txt`(타임스탬프 블록)와 `<id>.meta.json`(제목·채널·업로드일·길이·설명·챕터)을 Read한다. **전문을 다 읽는다** — 일부만 읽고 요약하지 않는다.
3. **정규화** — 자동자막이면 STT 오인식을 도메인 표기로 고친다. (§전사본 정규화) ⛔ 이 단계를 건너뛰고 분석하지 않는다.
4. **구조 복원** — 챕터가 있으면 그것을, 없으면 화제 전환 지점을 찾아 섹션으로 나눈다. 각 섹션에 **시작 타임스탬프**를 붙인다.
5. **분석·출력** — §출력 형식대로 터미널에 정리한다.

## 접근 불가·자막 없음

| 코드 | 상황 | 대응 |
|------|------|------|
| `3` | 멤버십 전용(`subscriber_only`)·Premium 전용·비공개·로그인 필요 | **중단하고 사유를 그대로 알린다.** ⛔ 쿠키 주입·계정 우회·다운로드 재시도 금지. 제목·채널 등 공개 메타는 알려주고, 다른 링크를 받을지 물어본다 |
| `2` | 영상은 공개인데 자막 트랙이 없음 | 중단하고 알린다. 제목·설명·챕터만으로는 내용 분석을 **하지 않는다**(추측 요약 금지). 사용자가 원하면 설명·챕터 수준의 개요만 제공한다고 밝힌다 |
| `4` | yt-dlp 설치 실패 | 네트워크·파이썬 환경 문제. 오류를 그대로 보여주고 중단한다 |

## 전사본 정규화

자동자막(`auto`)은 음성인식 결과라 **기술 용어와 숫자가 자주 깨진다.** 깨진 채로 요약하면 그 오류가 그대로 결론에 실린다. 아래 3종을 반드시 손본다.

| 종류 | 예 (실제 관측) | 처리 |
|------|----------------|------|
| **고유명사 표기** | `포스트레 SQL`·`포스트레스Q` → PostgreSQL · `시카리 CP`·`히카리시피`·`리가리 풀` → HikariCP · `이틀 스로우`·`리틀 슬로우` → Little's Law · `피지 바운서` → PgBouncer · `MVME SSD` → NVMe SSD · `단넷` → .NET · `와스` → WAS · `코리` → 쿼리 · `보화 테스트` → 부하 테스트 | 도메인 지식으로 복원. 설정 키는 원문 표기로(`maximumPoolSize`·`minimumIdle`·`leakDetectionThreshold`) |
| **숫자 왜곡** | `MySQL 맥스 커넥션이 15개` → 151 · `곱하기 1을 해 주는 겁니다` → ×2(앞뒤 문맥이 전부 코어×2) · `시작값 26으로 시작해서` → 16 | **앞뒤 문맥과 공식으로 교차 검증**한다. 계산이 안 맞는 숫자는 고치고, 근거가 없으면 `(추정)`을 붙인다 |
| **문장 뭉개짐** | `이 이`·`어,` 반복, 조사 붙은 `것이죠이` | 의미가 바뀌지 않는 선에서만 다듬는다. ⛔ 없는 내용을 채워 넣지 않는다 |

- **⛔ 창작 금지**: 화자가 말하지 않은 근거·수치·사례를 추가하지 않는다. 불확실한 복원은 `(추정)`으로 표시한다.
- **타임스탬프는 유지**: 정규화해도 `[MM:SS]` 앵커는 그대로 둔다. 나중에 원본 확인의 유일한 통로다.
- 수동 자막(`manual`)이면 정규화는 오탈자 수준으로 최소화한다.

## 출력 형식

터미널에 바로 출력한다. 파일은 전사본·메타 외에 만들지 않는다.

```
## <제목>
<채널> · <업로드일> · <재생시간> · 자막 <manual|auto>/<언어>

### 한 줄 요약
<이 영상이 결론적으로 무엇을 주장하는가>

### 구조
| 구간 | 내용 |
|------|------|
| 00:00–03:20 | 커넥션 풀 개념과 생성 비용 |
| ... | ... |

### 핵심 주장
1. [09:06] 풀 사이즈 시작점은 `코어 수 × 2 + 스핀들 수`예요. — 근거: PostgreSQL Wiki 경험칙
2. ...

### 수치·공식
| 값 | 의미 | 타임스탬프 |
|----|------|-----------|
| ... | ... | ... |

### 영상이 인용한 출처
- PostgreSQL Wiki (Number of Database Connections) — [09:06]
- ...

### 용어
| 용어 | 뜻 |
|------|-----|
| ... | ... |

### 검증이 필요한 지점
- [16:08] "곱하기 1"은 STT 오인식으로 보여요 — 앞뒤 문맥상 ×2예요. (정규화 반영)
- ...
```

- 사용자가 특정 관점을 요청했으면 그 섹션을 앞에 두고 나머지는 줄인다.
- **모든 주장에 타임스탬프를 붙인다.** 근거 없는 문장은 넣지 않는다.
- 카피는 해요체. 영상의 주장과 내 판단이 섞이지 않게 후자는 "검증이 필요한 지점"에만 쓴다.

## 절대 규칙

- **⛔ 접근 게이트 우회 금지** — 멤버십·Premium·비공개·연령 제한 영상은 사유를 알리고 **중단**한다. 쿠키 추출(`--cookies-from-browser`)·계정 로그인·프록시·대체 미러 탐색 전부 금지. 유료 콘텐츠는 권한이 있는 사람이 직접 본다.
- **⛔ 영상·오디오 다운로드 금지** — 받는 것은 **자막과 메타데이터뿐**이다. 음원을 받아 STT를 돌리지 않는다.
- **⛔ 자막 없으면 추측 요약 금지** — 제목·설명만 보고 내용을 지어내지 않는다. 자막이 없으면 없다고 말한다.
- **정규화 없이 분석 금지** — 자동자막은 반드시 §전사본 정규화를 거친다. 특히 **숫자는 공식·앞뒤 문맥으로 교차 검증**한다. 깨진 숫자가 결론에 실리는 것이 이 스킬의 가장 큰 실패다.
- **주장마다 타임스탬프** — 출력의 모든 주장·수치에 `[MM:SS]`를 붙인다. 원본 확인 경로를 끊지 않는다.
- **대상은 명시 링크만** — 사용자가 준 URL만 본다. ⛔ 관련 영상·채널의 다른 영상으로 확장하지 않는다.
- **작업 파일은 레포 밖에** — 전사본·메타는 스크래치패드 또는 `~/.rp-youtube/work/`에 둔다. 사용자 레포를 더럽히지 않는다.
- **영상의 주장과 내 판단을 구분** — 영상이 한 말은 그대로, 내가 의심하는 지점은 "검증이 필요한 지점"으로 분리한다. 외부 사실 검증까지 하려면 `rp-youtube-deck`을 쓴다.
- **전문을 읽는다** — 전사본 앞부분만 읽고 요약하지 않는다. 결론은 대체로 뒤에 있다.
